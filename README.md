# Keeper

**[Visit the Keeper website](https://kevinlong206.github.io/keeper-releases/)**
&middot; **[Downloads and release notes](https://github.com/kevinlong206/keeper-releases/releases)**

Keeper is a native digital audio workstation for Apple Silicon Macs, with
multitrack audio recording, take comping, non-destructive editing, MIDI,
Audio Unit support, mixing, and export.

Keeper is alpha software. See each release for system requirements,
installation instructions, and known limitations. Test with copies of projects
and keep backups.

This repository contains the public website and binary releases.
Keeper's application source code is not published here.

## Website

The site is plain HTML and CSS, with no build dependencies, scripts, analytics,
or external fonts. GitHub Pages publishes the root of the `main` branch.
`.nojekyll` keeps the site a direct static deployment.
